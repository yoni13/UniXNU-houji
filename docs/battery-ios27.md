# iOS 27 battery/charging draft

Reuse sheng's `AdspProbe.cpp`, `AdspFirmware.c`, `Qcom{Mdt,Smem,Smp2p,Glink,Qmp,Scm}.{c,h}`, `ShengBattmgr.{c,h}`, `ShengBattery.cpp`, and `BatteryProbe.cpp`; houji drafts are prefixed `Houji`. Reuse this repo's existing `QcomRpmh.c/.h`. iOS 16 also used QRTR/service-locator and UFS `modem_a`; this draft does not need QRTR and reads local Data files only. Its battery codec is intentionally read-only: unlike current iOS 16, it omits USB-limit, FCC, verification and input-suspend writes, dual-cell gauge extensions, current (polarity unverified), and inferred time remaining.

**Houji facts and evidence.** Stock houji DT (`$W/ref/UniXNU-houji-ios27/dts/houji.dts`; its reservations match `$W/private/stock-boot/dt/vendor_boot-*.dts`) gives SMEM `0x81d00000+0x200000`; IPCC `0x406000+0x1000`, SPI 229; ADSP DTB `0x9de80000+0x80000`; ADSP `0x9df00000+0x4680000`; AOSS `0x0c300000+0x400`; SMP2P in/out 443/429, remote PID 2; IPCC LPASS client 3, signals 0/2; and channels including `PMIC_RTR_ADSP_APPS`. The proven iOS 16 `HoujiAdsp.cpp` supplies PAS IDs 1/36, IPCC SPI 229, TCSR mutex `0x1f43000`, RSC `0x17a20000`/TCS `+0xd00`, cmd-db `0x81c60000+0x20000`, GLINK items 478/479/480 (FIFO `0x4000`), crash item 423, RSC SPI 5, and polling RSC because attaching that SPI froze boot. `$W/private/battery-ko/qti_battery_charger.ko` disassembly confirms board properties authentic 5, PD-verified 32, verify-process 20 and input-suspend 54 (the high word stored at message offset 12); none is written here. `docs/battery.md` records r263/r264: 89%, USB online/charging and plug/unplug transitions.

**Opt-in stages.** No argument means no mappings or service. `battery=1`: read-only SMEM/AOSS/RSC survey. `=2`: firmware parse, RPMh proxy votes, PAS DTB/ADSP boot. `=3`: SMP2P/GLINK and channel registration, no battery requests. `=4`: notification subscription and serialized standard battery/USB GETs, diagnostics only. `=5`: publish `IOPMPowerSource` only after valid capacity; update on complete refreshes.

Stage local `adsp.mbn` and `adsp_dtb.mbn` with `scripts/add-data-files.py` as `firmware/qcom/sm8650/houji/{adsp.mbn,adsp_dtb.mbn}:0`; default runtime path is `/private/var/firmware/qcom/sm8650/houji`, overridable by `houji_adsp_fw=DIR`. Never commit firmware.

**Before enabling stage 2:** add `no-map` reservations for SMEM, ADSP DTB and ADSP RAM to `dts/houji.dts`. They are below the configured high owned RAM `0x8c0000000-0x940000000`, but larger/alternate RAM windows could overlap; verify loader memory ownership and MDT span. Also resolve active-TCS ownership with Wi-Fi/touch, validate iOS 27 class-registration symbol handling, and host-test malformed SMEM/MDT/GLINK/messages. This is unbuilt, untested draft code.
