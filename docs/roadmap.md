# 待完成项与验收条件

2026-11-01 根据当前有效源码、截至 r293 的设备测试和固定版本上游记录复核。
“源码已实现”和“设备可用”分别记录；r229 亮度调节有响应，r231 的 2 GiB 主窗口进入桌面，文字、粉色与卡顿仍待修复，见[设备测试](device-tests.md)。

## 按依赖推进

采用上游[驱动适配顺序](https://unixnu.com/zh/porting/drivers)，下表用于安排实际接入；后面的优先级表用于描述缺陷严重程度。已能进入桌面不代表前置阶段全部通过，不需要删除已有功能后重做，但必须补齐相关证据再启用依赖它的快路。

| 顺序 | 本机已有证据 | 下一步与进入条件 |
| --- | --- | --- |
| 1. CPU、中断、RAM、DMA | 多核启动、调频、GPU 4 GiB 页表覆盖与高地址写回；有 Edge E/P 初始偏好适配 | 核对实际 UI 调度/中断延迟；r248 以来每次启动通过双向一致性及图像回读后启用快路；保留所有权检查，继续定位长映射阻塞 |
| 2. 存储与持久化 | HFSX 根卷可读写；r238 返回 Recovery 后全卷 256 块校验与只读快照一致，新增崩溃报告可回收 | 继续保留重启后的数据和日志；未完成异常掉电、长期随机 I/O 验证 |
| 3. 显示、刷新、亮度 | 原生几何、CPU 帧复制、完成后退休与 r229 亮度响应 | 先读本机 DPU/DSI/TE 状态并测帧时序，再选择 vblank 同步或直接扫描输出。当前软件 120 Hz 通知不能作为完成条件 |
| 4. 触控与按键 | 桌面/设置触控与键盘几何已实测 | 验证丢事件、连续手势和熄屏唤醒；把输入时间与呈现时间关联 |
| 5. GPU 与 Metal | 有界 GPU 写回、批量提交、缓存一致性和 WC 池；r273 紫色或乱码仍在，r274 动画无可感知改善 | r281 工作区局部视图已恢复桌面，动画仍卡；核对同一命令的锁持有者、完成等待与呈现；IOSurface 使用计数已在 r274 调用，颜色效果待确认。继续分场景验证清除、透明混合、文字纹理及其生命周期 |
| 6. Wi-Fi | 已有目标 DTS/固件与 PCIe/MHI/QMI 参考，尚未打通本机链路 | RC0/PHY/时钟/复位 → SMMU/DMA → MHI 固件 → QMI/WMI → 扫描/认证/IP；不能以开关或驱动注册代替联网 |
| 7. DSP、音频、电池与电源 | CPU/GPU 调频及 TSENS 已有独立路径；r263 ADSP 启动、真实电量与 USB 插拔状态已验证，充电控制及音频未完成 | 保留已验证的 PAS/SMEM/GLINK 电池通路，继续接入 GPR/AudioReach/CS35L41；验证电流与电池温控，已有 TSENS 温控继续生效 |
| 8. OS 服务与打包 | 当前 Darwin 22 ABI 和固定输入可构建 | 对每项服务核对 provider、参数布局和完成回调；全新环境构建与通用安装仍待验收 |

每阶段都要能追踪“源码 → 初始化调用 → 构建对象/链接符号 → 设备请求 → 完成/错误 → 释放”。上游 sheng 为 SM8550/A740，houji 为 SM8650/A750，且 OS ABI 不同；不按章节直接复制其寄存器或固件。

## 缺陷与验收

| 优先级 | 项目 | 当前缺口与下一步 | 完成标准 |
| --- | --- | --- | --- |
| P0 | GPU 调频与持续交互 | 默认开放完整工厂上限 903 MHz；r242 顶档请求驻留约 55.27% 仍明显卡顿。r255 已验证短时输入预升频和空闲降频，用户感到发热减少但动画仍卡 | 相同动作下帧间隔与延迟改善，HFI 无失败，空闲确实降频，无新错误 |
| P0 | 提交、内存与显示开销 | r248 缓存发布降至约 0.014 ms，桌面改善；r274 映射最长 224.752 ms。r281 修复工作区启动回归且映射最长降至 8.220 ms，但动画不改善；补齐锁持有者与 fence 关联；r278 接口约 120.659 Hz，仍需实际帧呈现同步；每进程 GPU 页表及 TE/vblank 仍未完成 | 冷/热缓存、连续滑动和开关应用均有设备记录，不能只看平均值 |
| P0 | 紫色阴影、文字与纹理错误 | 粉色位于单手模式上方和最近任务卡片阴影；r273 已运行纹理属性和双平面优化，紫色或乱码仍在。继续区分新纹理初始内容、清除、透明度和混合错误 | 同一场景的颜色/文本正确，且原 GPU 命令、纹理回收和失败路径均回归 |
| P0 | 温度与热保护 | r242 CPU/GPU 最高结温 98.1/85.3°C，用户明显感热，CPU 已限频；r255 减少不必要升频后用户感热下降，近期仍有 CPU 结温限频，需继续验证持续性能。PMIC 机身/电池温度与紧急关机仍缺失 | 温度读数可信、过温限制优先于交互升频、降温恢复有滞后；断线/异常有保守退路 |
| P1 | 墙纸与照片 | 照片黑屏已记录到 Photos 扩展失败、assetsd 反复退出及图库加载错误；精确调用兼容已实现，待验证。预览、权限与渲染继续分别检查 | 默认墙纸、图库缩略图、图片打开/缩放、切前后台均稳定，不能用截图局部出现判定完成 |
| P1 | 亮度与熄屏 | r229 用户确认本机 DSI0 / n3 面板亮度可调，DSI 无错误；仍需分类被拒绝的属性请求，并测完整范围和熄屏/唤醒 | 低/中/高亮度、熄屏/唤醒和连续拖动均实测；不复制平板背光芯片参数 |
| P1 | 电池与充电 | r263 已通过原厂 ADSP/PMIC GLINK 发布真实电量，用户确认显示及插拔切换；扩展协议、净充放电与电流符号仍需实测，未复制 USB 电流写入 | 插拔、充电方向、净电量变化及异常温度保护验证；出现图标不足以证明充电 |
| P1 | Wi-Fi | 参考 sheng 已连网的 Ath12kWifi 与同 SoC Ace 5 的 PCIe/MHI/QMI；仍缺本机 RC0/PHY/SMMU/DMA 和固件启动接入 | 扫描、关联、认证、DHCP、DNS、HTTPS、断线恢复和休眠唤醒均可复现 |
| P1 | 声音 | ADSP 启动/GLINK/GPR、AudioReach 路由、本机 CS35L41 功放/固件/时钟与 iOS 16 接口依次打通 | 有界已知 PCM 实际出声，停止/重启、音量、静音与错误恢复正确 |
| P2 | Safari | 本地 HTML 绘制已在 `houji_srgb=1` 下实测（2026-11-10）；仍需验证滚动、输入，再依赖网络验证 HTTPS；长期在 Metal 翻译层支持 RGB10A8 | 冷/热启动、多页、前后台和网络恢复通过；不能直接套用 iPadOS Cryptex 路径 |
| P2 | 蓝牙与蜂窝 | 需要各自控制器/固件、传输、协议及 iOS 服务接入，当前没有设备可用证据 | 分别建立可复现的连接与数据/音频链路，故障可恢复 |
| P2 | 启动与恢复 | UEFI SCM 停顿仍可能早于可恢复阶段；需保留最后阶段与失败分类 | 多次冷启动/重启有完整证据；不可捕获的早期锁死明确列为限制 |
| P2 | 构建与新版仓库格式 | 已补回漏导出的 SWEET 目标配置、14 个 HFS 源文件/头文件及本地 SDK HID 头文件准备步骤；format 2、SM8650 公共资源拆分和全新环境整机构建仍需工作 | 依赖版本可解析、源码组装一致、Darwin 22 ABI 不变、完整构建可重复 |
